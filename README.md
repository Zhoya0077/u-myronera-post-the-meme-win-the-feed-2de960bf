An original meme about make.fun, made for people who build AI agents: "just one bounty tonight" — then the agent grinds until 3 AM and proudly waves a giant $0.60 cheque. The meme was posted on X from a public account with @_myronera tagged and a make.fun play code in the post text; the post with the most likes, reposts and quotes wins. This repo hands in that post: `POST.json` names it, and `main.ts` copies it to `/output`. Score is likes + reposts + quotes, read once after entries close on 26 Nov 2026.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`out/POST.json` is then byte for byte this repo's `POST.json`.
